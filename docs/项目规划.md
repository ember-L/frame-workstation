# 项目规划

## 已确认决策

- 用户：个人创作者；目标平台：Apple Silicon macOS。
- 产品：Electron 桌面应用，FFmpeg 处理媒体，FFmpeg 随应用打包。
- 开发方式：分阶段交付，先完成单视频处理闭环，再加入 AI 和 Remotion。
- 首阶段导出：MP4、MOV、WebM；原分辨率或 1080p/720p/480p；高、中、低质量；每次选择保存位置。
- 字幕：本地 Whisper / 云端 OpenAI，可编辑、导出 SRT、选择烧录。
- 配音：本地 Piper / 云端 OpenAI，按字幕时间对齐；超时先适度加速，仍不匹配时提示用户；默认降低原声音量。
- 模板：图文解说与数据展示；表单编辑和 AI 起草均支持；参考 Remotion 官方示例，媒体由用户提供。
- 内容生成：OpenAI、DeepSeek、通义千问和自定义兼容接口。

## 当前状态

工作区已有第一阶段原型及导出参数测试。已使用本机 FFmpeg 对三种格式运行有声和无声样例编码；这不等于 Electron 界面、随包 FFmpeg、安装包或完整用户流程已经通过验收。Electron 和 FFmpeg 已安装，Electron 进程已启动，随包 FFmpeg 已对三种格式完成样例编码；完整桌面交互仍需验证。当前 FFmpeg 包含 nonfree 配置，已阻止打包，发布前必须更换并核查许可证。字幕已支持手动编辑与 SRT 导入导出，自动识别和烧录尚未实现。AI、Remotion 和多厂商接入尚未实现。现有界面只是原型，后续按本文件的 UI 工作流重新审视。

## 阶段与完成条件

### 阶段一：本地视频处理

1. 完善导入、预览、播放进度、单轨拆分/删除片段、速度、质量与分辨率设置。
2. 增加 GIF 导出：使用保留片段和速度设置生成无声 GIF。
3. 将 FFmpeg 任务与界面状态接通，处理取消、失败、异常素材和已有目标文件；确保源文件安全。
4. 分别验证有声、无声、横竖屏、短视频及不同编码的素材；验证三个输出格式、裁剪时长、音画同步、分辨率和质量差异。
5. 在 Apple Silicon 上验证随包 FFmpeg、应用启动与安装包；核对许可证及签名、公证要求。

**完成条件：**用户能从本地选择视频，经预览和调整后保存可播放的结果；明确已知限制，并有自动测试和实际导出证据。

### 阶段二：字幕

接入本地 Whisper 与云端 OpenAI；完成模型准备、配置、识别、逐条编辑、SRT 导出与可选烧录。验证中文及至少一个其他语言、有无语音、识别失败、时间调整和字幕编码。明确模型大小、设备要求及云端上传行为。

**完成条件：**用户可以生成、修正、导出字幕，并选择是否将其烧录进视频；两种模式分别经过实际验证。

### 阶段三：配音

接入 Piper 与 OpenAI 语音，按字幕时间生成和对齐音频，处理超时提示和原声音量。验证短句、长句、重叠时段、无原声和失败重试，确保配音不被静默截断。

**完成条件：**用户能审核字幕后生成可听、同步的配音，并导出混音视频；超时与失败有明确反馈。

### 阶段四：Remotion 与内容生成

核实 Remotion 官方示例、相关版本和许可证；实现图文解说与数据展示模板、表单编辑、预览和本地渲染。接入已确认的 LLM 厂商及自定义兼容接口，生成可修改的草稿；对用户素材、渲染失败、空数据和错误响应进行验证。

**完成条件：**用户可以手动或借助 AI 完成模板内容，审核数据后预览并导出视频；每种模板和已声明支持的服务均有实测记录。

## 横向检查与风险

- **数据安全：**源文件不覆盖；失败或中断时保护目标文件，检查路径别名、空间不足和权限错误。
- **密钥与隐私：**凭据使用系统安全存储，不进入日志；云端上传前明确数据范围与费用。
- **许可证：**核实 Electron、FFmpeg 构建和编解码器、Whisper、Piper、模型、Remotion 示例及素材的版本与分发许可。
- **性能：**实测本地模型的下载体积、内存、处理时间与散热；长任务保持 UI 响应。
- **可交付性：**锁定依赖，验证安装包、Apple Silicon 架构、签名及公证；未测试的能力不得标记为完成。

具体时间和各阶段发布节奏尚未估算，取决于真实设备、服务凭据、模型许可及集成测试结果。

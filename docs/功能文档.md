# 功能文档

## 产品目标与范围

为个人创作者提供一个本地桌面工作台：以单段视频为中心完成快捷处理，并逐步支持 AI 字幕、按字幕配音和模板视频生成。目标平台先覆盖 Apple Silicon macOS，不承诺第一版支持 Intel 或 Windows。

状态说明：**原型**表示已有相关代码，但未经过完整产品验收；**规划**表示已明确需求、尚未实现。

## 第一阶段：单视频处理

| 功能 | 用户需求 | 状态 |
| --- | --- | --- |
| 导入和预览 | 选择一个本地视频并预览，展示时长；无法解码时明确提示 | 原型 |
| 裁剪 | 播放进度条定位；在播放头拆分片段，选中片段后删除，按保留片段顺序拼接导出 | 已实现原型 |
| 变速 | 调整视频与音频速度，保持同步 | 原型，范围为 0.5–2 倍 |
| 压缩 | 提供高、中、低质量档位，兼顾画质与体积 | 原型；各格式的大小与画质仍需实测 |
| 分辨率 | 原分辨率、1080p、720p、480p；低于目标时不强制放大 | 原型 |
| 导出格式 | MP4、MOV、WebM；新增 GIF（无声音），MP4 为默认 | 已实现原型 |
| 保存 | 每次选择保存位置和文件名；不能覆盖源视频 | 原型，需验证边界情况 |
| FFmpeg | 随应用打包，不要求用户另行安装 | 已配置依赖和打包规则，打包结果及许可待验证 |

第一阶段支持单轨多片段保留与拼接，不包含多轨时间线、批量处理或字幕/配音/模板的正式功能。GIF 导出沿用速度、分辨率和保留片段设置，不包含音频。预览能力取决于 Electron 内置解码器；支持导入的文件扩展名不保证每种编码都能预览。

## 字幕（进行中）

已添加 SRT 导入、手动添加和逐条编辑、保存 SRT 的原型；未经过完整桌面交互验收。已加入导出时可选烧录，字幕采用源视频时间并随分段、变速同步；新增本地 whisper.cpp 和 OpenAI 识别原型；本地需自备可执行文件与 GGML 模型，云端需提供 API 密钥。两种模式尚需真实服务及模型验收。

- 从单视频语音生成带时间戳的字幕；支持本地 Whisper 和云端 OpenAI 两种模式。
- 在界面中逐条检查和编辑字幕文本、开始与结束时间；可单独导出 SRT。
- 导出视频时可选择将字幕烧录进画面；字幕不翻译作为当前已确认范围。
- 本地模式提供模型下载、状态和存储管理；云端模式由用户配置凭据并提示联网和费用。
- 对无语音、识别失败、模型缺失和时间冲突提供可理解的反馈；识别结果由用户审核。

## AI 配音（开发中）

已接入字幕配音生成与导出原型：支持本地 Piper（需自备可执行文件、ONNX 模型及配置）和 OpenAI（需 API 密钥），包括时间检查及原声混音；真实模型和云端服务尚未验收。

- 以字幕为输入，逐条生成语音并按字幕时间对齐；支持本地 Piper 和云端 OpenAI。
- 音频超出字幕时段时先适度加速；仍无法容纳则提示用户调整文本或时间，不自动改写字幕。
- 默认保留原视频声音并降低音量，使配音更清晰；具体默认音量和可调整范围待实现时验证。
- 支持选择可用声音，处理缺失音色、语言不匹配、生成失败和时间重叠；不能悄悄截断语音。

## Remotion 模板视频（后续阶段，规划）

- 首批提供**图文解说**与**数据展示**两类可编辑模板，参考 Remotion 官方示例与模板的动画和组合方式。
- 用户可选择模板，逐页填写或修改标题、正文、图片和数据，再预览并渲染视频；图片、视频及音乐由用户提供。
- 提供 AI 起草：输入主题后生成分镜、文案和图表内容，用户审核编辑后才能用于成片；图表数据需要用户核实。
- 不将官方示例、第三方资源或生成内容默认视为可无条件商用。每个采用的示例及依赖需在接入时核对许可证、素材归属和再分发条件。
- 音视频时长、分镜数量和模板输入限制以具体模板为准；不虚构尚不存在的官方媒体素材库。

## LLM 与配置（后续阶段，规划）

模板内容生成使用云端服务，首批预设 OpenAI、DeepSeek、通义千问，并支持自定义 OpenAI API 兼容接口。用户可配置接口地址、密钥和模型名称。兼容性、模型能力和接口差异需逐个验证；兼容接口不保证支持全部功能。字幕/配音服务与模板 LLM 的配置分别管理。

## 共同要求

- 明确展示处理中、成功、取消和失败状态；错误信息帮助用户处理问题。
- 保留源素材；导出失败不得破坏已有目标文件。
- 使用键盘可操作的控件、清晰标签和可辨识的状态；长任务不能让界面失去响应。
- 本地处理与云端传输的边界清楚，模型下载和云端调用前说明所需资源或费用。
